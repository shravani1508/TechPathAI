# TechPathAI – AI-Powered Student Career Roadmap

## About the Project
TechPathAI is a web-based career guidance platform designed to help students explore career opportunities, identify skill gaps, and plan their learning journey.

## Features
- **AI Career Advisor:** Get career guidance and answers to career-related questions.
- **Career Recommendations:** Explore career options based on your interests and skills.
- **Personalized Roadmap:** Follow a structured path toward your career goals.
- **Skill Gap Analysis:** Identify skills to improve for your chosen career.
- **Study Plan:** Organize your learning activities.
- **Progress Analytics:** Review your learning progress.
- **Student Profile:** Manage your personal and career information.
- **User Authentication:** Register and log in to your account.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP
- AI Integration: Google Gemini API

## How to Run the Project
1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs\`.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Create and configure the MySQL database using your local database configuration.
5. Keep API keys and database credentials in local configuration files. Do not upload secrets to GitHub.
6. Open `http://localhost/TechPathAI/` in your browser.

## Project Purpose
The goal of TechPathAI is to make career planning easier for students by combining career guidance, skill development, structured roadmaps, and progress tracking in one platform.
